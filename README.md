# Автотесты для API объявлений

## Описание
Автоматизированные тесты для проверки REST API сервиса объявлений (https://qa-internship.avito.com).  
Тесты написаны на Python с использованием `pytest` и `requests`.  
Покрывают позитивные, негативные и граничные сценарии для методов:
- POST /api/1/item
- GET /api/1/item/{id}
- GET /api/1/statistic/{id}
- GET /api/1/{sellerId}/item
- DELETE /api/2/item/{id}
- GET /api/2/statistic/{id}

## Требования
- Python 3.8+
- pip

## Установка
1. Клонировать репозиторий (или скопировать файлы).
2. Установить зависимости:
   ```bash
   pip install requests pytest

## Запуск тестов
- Все тесты: `pytest tests/`
- С подробным выводом: `pytest -v tests/`
- Для конкретной версии pytest `tests/test_api_v1.py`


## Конфиурация
Задать Базовый URL сервера в conftest.py.
При необходимости его можно переопределить через переменную окружения:
`export BASE_URL=https://qa-internship.avito.com
pytest tests/`

## Примечания
- Перед каждым тестом, где нужен существующий id, создаётся новое объявление (фикстура create_item).
- sellerId генерируется случайно в диапазоне 111111–999999 для изоляции тестов.
- Все тесты независимы и могут выполняться параллельно.
